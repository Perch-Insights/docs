Pick the path that matches what you need from Perch today. Each path is a short list of steps that links to the pages that show you how.

Whichever path you pick, start by [signing in and choosing a workspace](/getting-started/sign-in). You work inside a workspace.

<CardGroup cols={3}>
  <Card title="Analyze with the Guide" href="/getting-started/analyze-with-the-guide">
    Ask the Guide a question, get an insight report, and save a playbook you can run again.
  </Card>
  <Card title="View and monitor" href="/getting-started/view-and-monitor">
    Open your dashboards, read your alerts, and start an analysis when a number needs explaining.
  </Card>
  <Card title="Administer a workspace" href="/getting-started/administer-a-workspace">
    Manage the members, groups, and workspaces in your organization settings.
  </Card>
</CardGroup>

**Administer a workspace** is only for members who see the **Settings** button in the sidebar. Most members never see it.

New to Perch? Read [What Perch is](/introduction/what-perch-is) first.
