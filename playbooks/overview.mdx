After this page you will know what a playbook is, what happens when you run one, and where each run and its report are kept.

## What a playbook is

A playbook is a saved set of repeatable analyses you can run again with fresh data. You build it once in an analysis. After that, the Guide can repeat the same line of analysis whenever you ask.

Every playbook has a plan: the analysis steps the Guide follows on every run. Plan steps are not the numbered steps of an analysis. Numbered steps are the charts of one analysis. Plan steps describe what to do on any run.

## Where playbooks come from

A playbook starts in an analysis. You ask the Guide to save the analysis as a playbook. The Guide proposes one, and saves it only when you agree. The analysis you saved it from stays linked to the playbook.

## Runs

A run is one execution of a playbook. Each run is its own analysis, with its own steps and its own report. You own every run you start, even on a playbook another member owns.

Runs are numbered per playbook, starting at 1. Numbers can skip, so the number does not count finished runs.

## Reports from runs

The playbook page shows the **Latest run report**. This is the report from the most recent run. The **Past Runs** list below it holds every run. It also holds the analysis the playbook was saved from and any analyses used to change it.

A report does not change once it is finished. To get fresh numbers, run the playbook again.

## How playbooks relate to the rest of Perch

- A playbook is built from an analysis, and each run is an analysis. See [Analyses and the Guide](/analyses/overview).
- A run's report works like any other report. You can read its insights, copy them, and pin them. See [Reports and sharing](/sharing/overview).
## What you can and cannot change

A new playbook is private to you. Make it public so every member of the workspace can open and run it.

On a playbook you own, you can rename it, change its visibility, and set a schedule so it runs on its own and delivers its report to subscribers. You cannot edit the plan by hand. To change it, ask the Guide, and the Guide proposes the change for you to accept.

On a public playbook another member owns, you can read it, open its plan, run it, and open its runs. You cannot rename it, change it, or change its schedule or subscribers.
