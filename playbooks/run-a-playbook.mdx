After this page you will be able to click **Run** on a playbook, follow the run in its own analysis, read the **Latest run report** on the playbook page, and open any earlier run from the **Past Runs** list.

## Run a playbook

A run is one execution of a playbook. Each run gets its own analysis, and the Guide starts working in it as soon as it opens.

<Steps>
  <Step title="Open the playbook">
    Click the playbook's card in the **Playbooks** section of the analyses list, or the playbook chip in the **Playbook** column of an analysis that belongs to it. See [Save a playbook](/playbooks/save-a-playbook) for where to find them.
  </Step>
  <Step title="Click Run">
    Click **Run** at the right of the playbook header. Any member who can open the playbook can run it.
  </Step>
  <Step title="Follow the run">
    Perch opens the new run analysis. Until the Guide creates its first step, the canvas reads **The AI Guide is working on your first step**. Steps appear as the Guide creates them. The report appears in the **Guide** panel as an **Insight report** card. See [Read reports and insights](/analyses/reports-and-insights) for how to read, copy, and download it.
  </Step>
</Steps>

The run analysis is named with today's date, then **Run** and the run number, such as **July 3, 2024 • Run 7**. The line under its title reads **in** followed by the playbook name. Click that name to return to the playbook. You own the run analysis, so the owner badge reads **You**, even when the playbook belongs to another member. The run analysis also appears in the **Analyses** section of the analyses list, with the playbook chip in the **Playbook** column.

Run numbers count up separately for each playbook, starting at 1. Numbers can be skipped, so **Run 7** does not mean six earlier runs finished.

## Read the latest run report

<Steps>
  <Step title="Open the playbook page">
    The **Latest run report** card sits below the **Description**. Its header shows **Latest run report** and the name of the run analysis the report came from.
  </Step>
  <Step title="Read the report">
    The report is shown in a box under the header. The box scrolls on its own when the report is long. Click the header to collapse or expand the card.
  </Step>
  <Step title="Open the run">
    Click **Open run** at the right of the header to open the run analysis the report belongs to.
  </Step>
</Steps>

Until a run has produced a report, the card reads **No report yet**.

## Find past runs

<Steps>
  <Step title="Scroll to Past Runs">
    Below the report card, the **Past Runs** heading shows a count such as **Showing 8 of 8 runs**.
  </Step>
  <Step title="Filter and sort the list">
    The list has the same filters as the analyses list: a favorite filter that starts at **All**, an owner filter that starts at **All owners**, and a **Search...** field. Click a column header to sort.
  </Step>
  <Step title="Read the badges">
    A green **Latest report** badge marks the analysis whose report is shown in the **Latest run report** card. A run that is still working shows an **Executing...** badge. Perch shows this badge only for analyses created in the last hour.
  </Step>
  <Step title="Open a run">
    Click a row to open that analysis.
  </Step>
</Steps>

If nothing has been run yet, the list reads **No runs found**.

## Good to know

- Once the run finishes, the run analysis works like any other analysis you own. You can rename it, mark it as a favorite, and ask the Guide follow-up questions in the **Guide** panel.
- The playbook page refreshes the report about once a minute. Reload the page to see a run that has just finished right away.
- The **Past Runs** list is not limited to runs. It also includes the analysis the playbook was saved from and any edit analyses started with **Edit**. Runs started by other members appear too, unless their owner made them private. Use the owner filter to see only your own.
- Each card in the **Playbooks** section of the analyses list shows a **Last run** link with how long ago it ran. Click it to open that run analysis.
