---
title: "Save a playbook"
description: "Turn a thread's analysis into a playbook you can find on the analyses list and run again."
---

After this page you will be able to reply to a **Playbook proposal** in the chat to save it, open the playbook from the **Playbooks** section of the analyses list, read its description and **Plan**, rename it, and start an edit thread with the Guide to change it.
